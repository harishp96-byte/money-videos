# Audio library (Tamil Village Tales reels)

Only sounds that are safe to use on a monetised channel live here.

## Included
- `cc0-sfx-kit/` - from github.com/wyzowl/sfx-kit, CC0 (no credit needed). Foley touches/slides, props (splash, drip, bells), pops/bubbles, impacts, whooshes, swishes, shimmers, celebration, tones.
  Closest to our reel: pops (bubbling milk), props-splash/drip (water, clay), impacts (spade thunks), foley-wood/fabric (wheel, cloth), shimmer + shop-bell (Pongal).

## Not included (checked, not suitable)
- ESC-50 (karolpiczak/ESC-50): CC BY-NC, non-commercial. Only its ESC-10 subset is CC BY.
- psfx (JimHPerry/psfx): custom PSFX licence PDF, Foundry VTT oriented, not reviewed for YouTube use.
- ion-assets (gbaptista/ion-assets): sci-fi HUD sounds, not relevant.
- eryon/SoundFxLibrary: repo not publicly reachable.

## Still missing (no free GitHub source found)
